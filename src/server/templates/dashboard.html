Edge Impulse studio manual workflow appendix

Status: Not executed (Theoretical survey and manual workflow reference)
  1. Create project in Edge Impulse Studio, select "Accelerometer data" for HAR and "Audio" for KWS.
  2. Upload raw UCI HAR 6-axis csv windows and Speech Commands 16 kHz wav files via Edge Impulse CLI uploader.
  3. Configure Impulse: 128 samples at 50 Hz → Raw Data Block → Classification (Keras 1D-CNN).
  4. Train model using EON Tuner, inspect confusion matrix and on-device performance estimates.
  5. Deploy as C++ library or CMSIS-NN pack, compile using Keil MDK or Arm GCC.

Data and privacy policy

Transparency regarding sensors, processing locality, logging policies, and dataset licenses.

Sensor access and processing locality

Sensors accessed: The phone interface reads accelerometer (total acceleration including gravity) and gyroscope (rotation rate in radians per second) via the browser DeviceMotionEvent API. The microphone is accessed via the Web Audio API (getUserMedia) downsampled to 16 kHz PCM.

Locality of processing: All TinyML inference runs strictly locally on the user laptop host. Raw audio and motion samples are streamed into transient in-memory ring buffers and are not written to disk during live operation.

Event logging: When an emergency alert fires, only the timestamp, classification label, confidence score, and the name of the triggering rule are recorded in the event log. You can clear this history anytime using the button on the Live classification page.

Notice and terms

Educational prototype terms, medical disclaimers, and documented operational limitations.

Educational prototype notice

This system is an academic research prototype prepared for the course "Introduction to AI and Embedded Systems". It is not a medical device, has not undergone clinical certification, and must never be used for real healthcare monitoring, fall alerting, or emergency medical response. No warranty of fitness for any purpose is provided.

Documented operational limitations:
  • The UCI HAR dataset does not contain an empirical fall class. The fall detector uses a heuristic impact-spike rule with ML posture confirmation, tested on synthetic impact traces.
  • The Google Speech Commands dataset does not include the word "help". The system uses "stop" as the configurable emergency keyword.
  • Live phone sensor accuracy will be lower than held-out test accuracy due to variable pocket placement, accelerometer noise, and client-side web browser timing jitter.
  • Inference timing numbers on desktop CPU are relative benchmarks, not hardware measurements on physical silicon.
